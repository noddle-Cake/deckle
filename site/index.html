Scanning

Works with the scanner you have.

USB or network, flatbed or feeder. Set it up once, and the options you used last are ready next time.

  • Finds your scanner

    WIA and TWAIN on Windows, SANE on Linux and macOS, and driverless network scanners everywhere.

  • Fixes pages for you

    Turns sideways and upside-down pages upright, straightens crooked ones and skips the blanks.

  • Handles big jobs

    Batch scans, saved profiles and scan merge, which puts two-sided documents in order without a duplex feeder.

Saving

Files that arrive finished.

No export step to remember. Deckle saves as you scan, in the folder you chose, under a name that makes sense.

  • Searchable PDFs

    Text recognition in more than 100 languages, plus PDF/A, metadata and password protection.

  • Names that mean something

    Build file names from the date, a running number, the scanner and your own text.

  • The format you need

    PDF, JPG, PNG, TIF or BMP. Or copy a page to the clipboard and share it without saving at all.

How it works

From paper to PDF in 4 steps.

  1. Step 1

    Choose

    Pick your scanner, color and resolution.

  2. Step 2

    Scan

    Press Scan. Pages appear as they come in.

  3. Step 3

    Tidy

    Crop, reorder, adjust or draw, if you need to.

  4. Step 4

    Done

    The file is already saved in your folder.

Open source

Free to use. Open to everyone.

Deckle costs nothing and has no account, ads or subscription. Your scans stay on your computer: it only goes online to find network scanners and to fetch the language packs you ask for.

Get Deckle.

Always the latest build. Nothing else to install: everything it needs is in the download.

Windows

Windows 10 and 11. Run the installer; no administrator rights needed. Windows may warn that it is from an unknown publisher: choose More info ▸ Run anyway.

Installer Zip

macOS

Move Deckle to Applications. It isn't notarized by Apple yet, so allow it in System Settings ▸ Privacy & Security the first time.

Apple Silicon Intel

Linux

Unpack and run Deckle. Install SANE and your scanner's backend for USB scanners.
